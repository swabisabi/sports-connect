# Reaching athletes and bringing them into the web app

The web app is the sign-up front door. WhatsApp stays where the community lives. A web page cannot read or import WhatsApp members, so each person opens the link and signs up themselves.

Flow: poster / post / friend -> web app (sign up) -> sport group on WhatsApp -> session.
